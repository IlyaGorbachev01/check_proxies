# 🚀 Telegram Proxy Checker

Быстрый, легковесный и асинхронный CLI-инструмент на Python для проверки работоспособности списка MTProto-прокси для Telegram.

## 📋 Описание

Скрипт автоматически получает список прокси-ссылок (из локального файла или с GitHub), асинхронно проверяет доступность каждого сервера через TCP-соединение и сохраняет только рабочие ссылки в отдельный файл.

Благодаря асинхронности (`asyncio`) и легковесным структурам данных (`NamedTuple`), скрипт способен проверить тысячи прокси за считанные секунды, не нагружая систему.

## ✨ Возможности

- ⚡ **Высокая скорость** — асинхронная проверка до 100+ прокси одновременно.
- 📦 **Нулевые зависимости** — используются только встроенные библиотеки Python.
- 🌐 **Автозагрузка** — при первом запуске автоматически скачивает актуальный список прокси с GitHub.
- 💾 **Экономия трафика** — повторные запуски используют локальный файл.
- 🛡️ **Сохранность данных** — оригинальные URL (включая `secret`) сохраняются без изменений.
- 📊 **Наглядный вывод** — прогресс-бар в реальном времени и цветовая индикация через эмодзи.
- 🔧 **Гибкая настройка** — все параметры доступны через аргументы командной строки.
- ⌨️ **Корректное завершение** — обработка `Ctrl+C` без вывода стек-трейса.

## 🚀 Быстрый старт

### 1. Клонируйте или скачайте проект

```bash
git clone <url-репозитория>
cd proxy_checker
```

### 2. Запустите скрипт

```bash
python check_proxies.py
```

При первом запуске скрипт **автоматически скачает** актуальный список прокси с GitHub в папку `data/`. При последующих запусках будет использоваться локальный файл.

### 3. Получите результат

Рабочие прокси будут сохранены в файл `data/working_proxies.txt`.

## 📖 Использование

### Базовые команды

```bash
# Запуск с настройками по умолчанию
python check_proxies.py

# Принудительно обновить список прокси с GitHub
python check_proxies.py --refresh

# Увеличить таймаут до 10 секунд (для медленных серверов)
python check_proxies.py --timeout 10

# Ограничить количество параллельных проверок
python check_proxies.py --workers 50

# Использовать свои файлы
python check_proxies.py --input my_proxies.txt --output my_working.txt

# Комбинировать аргументы
python check_proxies.py --refresh --timeout 15 --workers 75
```

## 🔍 Как это работает

1. **Получение списка** — скрипт проверяет наличие локального файла. Если его нет (или указан `--refresh`), скачивает актуальный список с GitHub.
2. **Парсинг** — из каждой строки URL извлекаются `server`, `port` и `secret` в неизменяемую структуру `Proxy` (`NamedTuple`).
3. **Проверка** — для каждого прокси устанавливается TCP-соединение через `asyncio.open_connection`. Если сервер отвечает — прокси считается рабочим.
4. **Сохранение** — оригинальные URL рабочих прокси записываются в выходной файл.

> ⚠️ **Важно:** Скрипт проверяет **сетевую доступность** сервера (открыт ли порт), но не выполняет криптографическое рукопожатие MTProto. Прокси будет помечен как рабочий, если сервер онлайн, даже если параметр `secret` устарел. Для фильтрации "мёртвых" IP из больших списков это оптимальный баланс скорости и точности.

## 🌐 Решение проблем с загрузкой

Если при первом запуске вы видите ошибку:

```
❌ Не удалось получить файл: <urlopen error [Errno 11004] getaddrinfo failed>
```

Это означает, что `raw.githubusercontent.com` недоступен (часто блокируется провайдерами в некоторых регионах).

### Варианты решения:

**1. Используйте VPN или прокси**
Включите VPN и запустите скрипт снова.

**2. Скачайте файл вручную**
Откройте в браузере (через VPN):
https://raw.githubusercontent.com/SoliSpirit/mtproto/master/all_proxies.txt

Сохраните содержимое в файл `data/all_proxies.txt` и запустите скрипт без флага `--refresh`.

**3. Укажите альтернативный источник**
Поместите свой список прокси в любой файл и укажите его через `--input`:

```bash
python check_proxies.py --input path/to/your/proxies.txt
```

## 🔧 Настройка

Основные параметры можно изменить непосредственно в коде (`check_proxies.py`):

```python
# Константы по умолчанию
DATA_DIR = Path("data")
DEFAULT_INPUT_FILE = DATA_DIR / "all_proxies.txt"
DEFAULT_OUTPUT_FILE = DATA_DIR / "working_proxies.txt"

REMOTE_PROXY_LIST_URL = (
    "https://raw.githubusercontent.com/SoliSpirit/mtproto/master/all_proxies.txt"
)

DEFAULT_TIMEOUT = 5          # Таймаут подключения (сек.)
DEFAULT_WORKERS = 100        # Параллельных проверок
```

> 💡 **Совет:** Если ваш провайдер ограничивает количество одновременных соединений, уменьшите `DEFAULT_WORKERS` до `50` или `30`.

## 🏗️ Архитектура

Код организован по принципу разделения ответственности:

- **`Console`** — централизованный вывод с уровнями логирования (`LogLevel` enum).
- **Бизнес-логика** — чистые функции без побочных эффектов (`parse_proxy`, `download_proxies`, `load_proxies_from_file`, `check_proxy`).
- **Оркестрация** — функция `main()` координирует процесс.

Такой подход делает код читаемым, тестируемым и легко расширяемым.
