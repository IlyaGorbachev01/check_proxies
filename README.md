# 🚀 Telegram Proxy Checker

Быстрый, легковесный и асинхронный скрипт на Python для проверки работоспособности списка MTProto-прокси для Telegram.

## 📂 Структура проекта

```text
proxy_checker/
├── check_proxies.py         # Основной скрипт
├── README.md                # Этот файл
├── .gitignore               # Настройки игнорирования для Git
└── data/                    # Директория для файлов с данными
    ├── all_proxies.txt      # Входной файл: ваш список прокси для проверки
    └── working_proxies.txt  # Выходной файл: результат (создаётся автоматически)
```

## 📋 Описание

Скрипт читает файл со списком прокси-ссылок, асинхронно проверяет доступность каждого сервера через TCP-соединение и сохраняет только рабочие ссылки в новый файл.

Благодаря использованию асинхронности (`asyncio`) и легковесных структур данных (`NamedTuple`), скрипт способен проверить тысячи прокси за считанные секунды, не нагружая систему. Директория `data/` автоматически создаётся при первом запуске, если её не существует.

## ✨ Особенности

- ⚡ **Высокая скорость:** Асинхронная проверка до 100+ прокси одновременно.
- 📦 **Нулевые зависимости:** Используются только встроенные библиотеки Python (`asyncio`, `urllib`, `pathlib`).
- 💾 **Эффективность:** Минимальное потребление памяти.
- 🛡️ **Безопасность данных:** Оригинальные URL-адреса сохраняются в неизменном виде. Папка `data/` по умолчанию исключена из Git.
- 📊 **Наглядность:** Прогресс-бар в реальном времени с отображением процента выполнения и количества найденных рабочих прокси.

## ⚙️ Требования

- **Python 3.10** или выше.

## 🚀 Быстрый старт

1. **Подготовьте входные данные:**
   Создайте папку `data` в корне проекта (или просто запустите скрипт, он создаст её сам).
   Поместите в неё файл `all_proxies.txt`. Каждая строка должна содержать одну прокси-ссылку.
   *Пример содержимого `data/all_proxies.txt`:*
   ```text
   https://t.me/proxy?server=example.com&port=443&secret=abc123
   https://t.me/proxy?server=another-site.net&port=8443&secret=xyz789
   ```
2. **Запустите скрипт:**
   Откройте терминал или командную строку в корне проекта и выполните:
   ```bash
   python check_proxies.py
   ```
3. **Получите результат:**
   После завершения проверки все рабочие прокси будут автоматически сохранены в файл `data/working_proxies.txt`.

## 🔧 Настройка

В начале файла `check_proxies.py` есть блок констант, которые вы можете изменить под свои нужды:

```python
DATA_DIR = Path("data")
INPUT_FILE = DATA_DIR / "all_proxies.txt"       # Путь к файлу со списком для проверки
OUTPUT_FILE = DATA_DIR / "working_proxies.txt"  # Путь к файлу для сохранения результатов
TIMEOUT_SECONDS = 5                             # Таймаут на попытку подключения (в секундах)
MAX_CONCURRENT_CHECKS = 100                     # Максимальное количество одновременных проверок
```

> **💡 Совет:** Если ваш интернет-канал или провайдер ограничивает количество одновременных соединений, уменьшите значение `MAX_CONCURRENT_CHECKS` до `50` или `30`, чтобы избежать ошибок `OSError`.

## 🔍 Как это работает (Технические детали)

Скрипт проверяет **доступность TCP-порта** на указанном сервере.
1. Он извлекает `server` и `port` из URL.
2. Пытается установить TCP-соединение (`asyncio.open_connection`).
3. Если соединение успешно установлено в пределах `TIMEOUT_SECONDS`, прокси считается "живым" (порт открыт и сервер отвечает).
4. Если происходит таймаут или отказ в соединении, прокси помечается как нерабочий.

> **⚠️ Важное примечание:** Скрипт проверяет именно *сетевую доступность* сервера. Он не выполняет полноценное криптографическое рукопожатие протокола MTProto. Это означает, что прокси будет помечен как рабочий, если сервер онлайн, даже если параметр `secret` устарел или неверен. Однако для фильтрации больших списков от "мёртвых" IP-адресов этот метод является золотым стандартом по соотношению скорость/точность.
